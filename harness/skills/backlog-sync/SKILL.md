# Backlog synchronization

1. Scan project TODO/FIXME files, issue exports, dev notes, and open handoffs.
2. Remove duplicates and separate stale notes from actionable work.
3. Create one TimeKeeper Task per real outcome.
4. Put source file/line references and acceptance evidence in the Task description or Project note.
5. Create bounded Sprints only for the next executable work.
6. Re-read the tree and events to verify every imported item landed once.

Never mark a TODO complete because a similarly named file changed. Completion needs evidence.
